⚠️ Supabase backend тохируулаагүй тул зөвхөн энэ browser дээрх урилгууд харагдана. Backend тохируулбал бүх төхөөрөмжөөс харах, хариу цуглуулах боломжтой болно (assets/config.js).

🔎 Урилгаа ID эсвэл линкээр нь хайх

Энэ хуудас нь энэ browser-с үүсгэсэн урилгуудыг сануулж харуулдаг. Өөр утас/компьютерээс үүсгэсэн, эсвэл түүх нь арилсан бол урилгын линкээ доор буулгаад нэмээрэй — нэг л удаа нэмбэл цаашид жагсаалтад үлдэнэ. Ингэж нэмсэн урилгыг зөвхөн жагсаалтаас хасаж болно — бүрмөсөн устгахын тулд уг урилгыг үүсгэсэн browser-ээсээ орно уу.
