Энэ хуудсыг зөвхөн та л харна. Урилгын линкийг илгээсэн crush эсвэл бусад хүн энэ жагсаалт руу нэвтрэх боломжгүй — жагсаалт нь зөвхөн энэ browser дээр хадгалагдана. Өөр browser эсвэл утаснаас хариу харах бол доорх "Урилгаа сэргээх"-ээр эрхийн кодоороо буцааж авна уу.
🔑 Урилгаа сэргээх — өмнөх эрхийн кодоороо

Browser цэвэрлэсэн, өөр төхөөрөмжөөс нэвтэрсэн үү? Урилга үүсгэхэд ашигласан LOV-XXXXXX кодоо оруулаад тухайн урилгын хариугаа энэ browser-т сэргээгээрэй. Код нь QPay төлбөрийн түүхэнд эсвэл өмнө хуулж авсан газарт байгаа.

⚠️ Supabase backend тохируулаагүй тул зөвхөн энэ browser дээрх урилгууд харагдана. Backend тохируулбал бүх төхөөрөмжөөс харах, хариу цуглуулах боломжтой болно (assets/config.js).
